# Pandas Mini Projects

This folder contains small Python scripts that demonstrate common pandas
operations for data analysis. Each script reads sample CSV files from the
`data/` directory and prints results to the console.

## Projects

1. **01_basic_operations.py** - Loading data, inspecting DataFrames and
   selecting columns.
2. **02_filtering_sorting.py** - Filtering rows, sorting, and creating new
   columns.
3. **03_groupby_aggregation.py** - Using `groupby` and `agg` to summarize
   data.
4. **04_merge_join.py** - Merging and joining DataFrames.

Run any script with `python <script_name>` from this directory.
